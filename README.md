BAD EVIDENCE

BAD EVIDENCE is a one-button text app for terrible proofs, social alibis, weak evidence, institutional excuses, and suspicious conclusions.

It generates compact satirical cards in the form:

Proof that [claim]: [bad evidence exposing the bad proof].

The app is designed as a small “exhibit terminal”: a browser-based machine that produces bad reasoning with enough clarity to make the failure visible.

What It Does

BAD EVIDENCE deals one card at a time from a deck of 999 short text cards.

Each card presents a fake or compromised proof: not a random joke, but a small failure of reasoning, power, memory, procedure, branding, bureaucracy, intimacy, status, or public language.

The aim is to expose how people, institutions, families, platforms, workplaces, and markets often treat weak evidence as if it were proof.

Interface

The interface has four main controls:

SHOW THE PROOF — generates a new BAD EVIDENCE card.
COPY — copies the current card.
CLEAR — resets the output area.
ABOUT — opens the app description and deck count.

The app keeps no persistent user history. It runs entirely in the browser.

Visual Design

BAD EVIDENCE uses a dark terminal / evidence-room aesthetic with:

amber and red evidence colours
CRT-style scan texture
a structured output box
a faded circular PROOF stamp
worn / washed stamp texture
animated stamp pulse when a card is generated
a matching circular stamp favicon

The stamp sits at the top of the output box, above the generated text, as if the card has been physically marked before entering the record.

Card Style

Cards should remain:

sharp
compact
readable at a glance
structurally witty
grounded in recognisable behaviour
clear about the failure of evidence
suspicious rather than merely silly

A strong BAD EVIDENCE card does not just make a joke. It reveals why the supposed proof is bad.

Good Example

Proof that the policy is for the people: the people harmed by it appear under exceptions.

This works because the second half exposes the hidden exclusion inside the official claim.

Weak Example

Proof that the policy is for the people: which people is in fine print.

This is understandable, but thinner. It points at the problem without fully dramatizing the bad logic.

Editorial Principle

BAD EVIDENCE is about evidence failure.

The card should make the reader feel the bad inference happening.

Common patterns include:

circular proof
selective evidence
institutional self-protection
social pressure mistaken for agreement
silence mistaken for consent
performance mistaken for care
procedure mistaken for justice
visibility mistaken for truth
confidence mistaken for reliability
documentation mistaken for repair
exhaustion mistaken for closure
Technical Notes

BAD EVIDENCE is built as a standalone HTML file containing:

HTML structure
CSS styling
JavaScript logic
embedded card deck
inline SVG favicon
inline SVG stamp graphic

No package manager, framework, bundler, or backend is required.

To run it:

Download the HTML file.
Open it in any modern browser.
Press SHOW THE PROOF.
Privacy

The app does not send data anywhere.

It does not require a login, store user input, use cookies, or contact a server. Copying text uses the browser clipboard API only when the user presses COPY.
